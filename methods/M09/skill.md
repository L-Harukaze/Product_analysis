# M09 保值率

**方法编号**：M09｜**版本**：v0.1（未实跑）｜**学科**：经济学包（F1低频高价触发；S3耐用栈）
**继承**：《_shared/discipline.md》+《_shared/protocol.md》+《_shared/contract.md》，本文件只写包级内容。
**预算**：time_limit: 600 s（P-2 单方法执行上限；v0.1 统一默认值，实跑后按方法实测调定）

## 1. 方法边界声明

本方法分析**产品残值随时间/里程的衰减结构（保值率）**。范围外：二手车交易流程与车况评估（检测维度，登记）；残值对 TCO 的折算细节（M06 辖区——本方法只输出残值曲线，折算由 M06 消费）；金融租赁产品设计（登记）。输入出现相关证据→method_xref 登记不展开。

## 2. 方法定义

**理论内核**（L2 只许援引）：
- **残值曲线**——保值率=二手价/MSRP 随时间/里程衰减；耐用品的资产属性维度；
- **衰减结构**——首年陡降+长尾缓降的指数近似；品牌/供给约束/技术迭代速度是衰减斜率的结构因子；
- **样本偏差警示**——挂牌价≠成交价；在售样本自选择（急售/车况差占比高），保值率有系统性偏误方向。

**前置条件（STEP 0 机械检查）**：P1 二手市场报价序列可得；P2 车龄-价格配对可建。**两条件缺失=本方法预期常态，直接走降级形态，不视为异常。**

**已知混杂（逐条检查）**：
- C1 挂牌价 vs 成交价（系统性高估，须注记口径）
- C2 样本自选择（在售二手车源非随机样本）
- C3 新车降价传导（官方调价使二手价联动，衰减不全归产品本身）

**已知局限（不得隐去）**：新上市车型无二手样本，本方法对该类对象**只能输出行业基准参照+缺口报告**；保值率受区域/车况离散度大，曲线为带非线。

## 3. 执行流程

**STEP 0 预检**：P1-P2。不满足→**直接进入降级形态**（STEP 4），这是预期路径非异常。

**STEP 1 二手报价采集**：residual_quotes 表 {object, age_months, mileage, asking_price, msrp, retention_rate, source}。

**STEP 2 保值率曲线**：数据 ≥3 个时点才成线（<3→点状登记不成线）；分车龄段保值率带（区间输出禁单值）。

**STEP 3 竞品对比**：同车龄段竞品保值率对照；口径差异（挂牌/成交、样本量）注记。

**STEP 4 降级形态（缺数据时）**：RESIDUAL_DATA_MISSING 触发→行业基准参照（同级车首年保值率带，第三方口径）+缺口报告，**不编造本品曲线**。

**STEP 5 输出联动**：残值组件（或缺失事实）经 method_xref 输出给 M06（TCO 残值项）。

## 4. 降级规则与 flag 枚举表
