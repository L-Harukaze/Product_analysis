## 1. 方法边界声明

本方法分析产品**价格话语中的锚定结构与参照点算术**。以下维度不在 M04 范围内：
- 版本菜单内部的诱饵/自我选择机制（M03 辖区——锚点与档位阶梯构成诱饵结构时，登记不展开，出 method_xref）
- 非价格维度的锚定（参数宣言、续航数字等，v0.2候选：M04-ext-nonprice）
- 价格作为质量信号的投资机制（S2 信任栈辖区——衔接点登记不展开）

输入数据中出现相关证据时，不展开分析，仅在 method_xref 或边界注记中登记。

## 2. 方法定义

**理论内核**（三条支柱，L2 只允许援引这三条）：
- **Tversky-Kahneman 锚定与调整**——决策者自锚值出发调整不足，后续价值判断被系统性偏移；
- **前景理论参照点依赖**——得失以参照点感知而非绝对水平，损失厌恶使"低于锚点"的 framed gain 有非对称行为效力；
- **外部锚→内部参照价**——划线价、对标宣言、成本宣言等外部锚塑造消费者内部参照价，后者决定感知成交价值（营销参照价理论）。

**锚的三分类**（M04 分析对象）：
- **A类·竞品锚**：话语指向竞品价格（对标宣言）
- **B类·自有锚**：话语指向本产品其他价格点（预售价、高配价、历史价、心理价位宣示）
- **C类·非价格锚**：成本宣言、价值叙事等无外部参照对象的话语——入 anchors 表登记并标"非价格锚定"，**不进入 offset 算术**〔S5〕

**与 S2 信号栈衔接点**：锚话语若兼有质量信号功能（以高价宣示品质），登记 method_xref(S2-signal) 后不展开。

**前置条件（STEP 0 机械检查）**：
- P1 表E价格类话语≥2条且参照对象可识别（仅1条→触发 E_MISSING，单点登记模式，禁止判"系统性锚定方向"）
- P2 每条话语的参照对象存在可取得的市场价（或可标区间）
- P3 话语时点可锚定至年月级

**已知混杂（每条诊断项必须逐条检查污染）**：
- C1 权益/金融方案：感知成交价的比较基准是有效价，offset 须官方价/有效价双口径并列，禁止混用
- C2 竞品时点错位：参照价必须取话语发布时点的价格，跨时点 offset 禁止（Model S 时点判例为规范来源）
- C3 多锚干扰：高低锚并存时净方向不可加总；判"整体锚定策略"必须列锚组合，禁止单锚结论外推全案
- C4 结构漂移：锚有效性检验用表G结构数据，但结构变动同时受供给、交付节奏、竞品上市影响——只允许相关级判断

**已知局限（输出不得隐去）**：内参价不可直接观测，全部"有效性"判断为话语—结构的相关性推断，非因果；话语池限于公开可得信源，私域与未索引投放不在内，锚清单可能系统性不全；锚定强度的心理量不可观测，本方法只输出锚结构与 offset 算术。

## 3. 执行流程

**STEP 0 预检**：读全部输入表→查 P1-P3→不满足则终止并输出缺哪条。

**STEP 1 锚提取**：表E→anchors 表 {anchor_id, date, tier(可选), quote_original, claimed_reference, anchor_type(A/B/C), implied_ref_price(口径注记)}。
- 拆分规则〔S5〕：一条话语含多个参照对象→拆为多行（编号a/b）；无外部参照的成本宣言→入表标 C 类
- quote_original 保持输入表原文引句〔S12〕

**STEP 2 参照价锚定**：表F+表C→ref_prices 表 {anchor_id, ref_object, ref_price, ref_price_interval(可选), event_date, source}。
- **时点锚定条款〔Model S判例〕**：参照价取"话语发布时点最近的可得事件价"，必注 event_date；参照价带时点近似注记的，offset 按注记口径处理（区间或下沿+声明）
- 表F缺对应时点→data_gap_reports 登记，降级用最近可得价+区间注记，置信=估算

**STEP 3 offset 计算**：{anchor_id, offset, offset_interval(可选), price_basis, confidence}。
- 符号约定〔S5〕：offset=本产品价−参照价（负=低于参照）
- 本产品价口径默认指导价；权益并轨（STEP 5）提供有效价双轨——两口径 offset **同列不平均**，符号分叉时单独登记
- 参照价带区间→offset 按区间输出；区间跨零→"方向不可判"，禁中点/单值结论；衍生数据置信=估算〔S3〕

**STEP 4 锚有效性检验**：
- a) 锚序结构：按时间序列出锚事件，判锚定策略形态（单点高锚/先高后低/多点组合）；先高后低→检查后续价格事件是否构成"得框架"（后价≤先锚→感知得），结果登记 timeline
- b) 结构交叉验证：表G取锚事件前后窗口，比对结构漂移方向与锚方向是否相容——**输出强制标"相关级判断"**，无数据→flag C4_NO_SALES_DATA 标"不可检"，禁止因果措辞
- c) 诱饵混淆检查：某锚的 implied_ref_price 与本产品高配价高度邻接→登记 method_xref(M03)，注记"该锚可能同时构成版本菜单诱饵结构"，不展开
- d) 非单调锚定：锚方向与后续实际定价冲突→单列，机制解释标"证实/推断"〔M03 STEP4c 范式〕

**STEP 5 权益并轨（分级，全继承 M03）**：B_detail→精确折算，timeline V2 双带；B_events→媒体口径近似（置信=估算），timeline V2e 事件带禁插值；皆无→B_MISSING。权益事件含选装价格变动的部分按边界声明登记不展开。

**STEP 6 冲突检测（定点检查制〔S13〕，三类枚举检查点，每类一次）**：
- ① 同表同主题互洽：表E话语时点↔anchors拆分一致性；表F同一参照对象多行价格的时间序列互洽
- ② 跨表同事实核对：anchors.implied_ref_price↔ref_prices.ref_price 逐锚对照；表F参照价↔表C价格事件可回溯对应
- ③ 时点对齐核对：锚话语日期↔ref_prices.event_date 顺序性（event_date≤话语日期+已声明的近似窗）
- 冲突→裁决顺序：算术互洽→置信等级→口径核对；可裁决→留痕；不可裁决→data_gap_reports
- **凡反推类结论〔S11判例〕**：显式列出全部假设——必须包含所有被固定或近似的变量，按假设给方向界而非点估计，并说明假设变动时结论如何移动

## 4. 降级规则与 flag 枚举表（flag 名称固定，跨运行可比）

| flag | 触发条件 | 动作 |
|---|---|---|
| E_MISSING | 表E无价格类话语，或仅1条 | 终止系统性分析并输出原因；仅1条时降级单点登记模式（本flag照触发） |
| REF_PRICE_TIME_MISSING | 表F参照价无时点注记且无法锚定话语时点 | 该 offset 置信=估算+区间注记 |
| B_MISSING | B_events 与 B_detail 均无〔继承〕 | price_effective=指导价，权益归因证据不足 |
| B_PARTIAL_NEWS | 仅 B_events〔继承〕 | 权益折算=媒体口径近似（估算级），timeline V2e |
| C_TIMELINE_PARTIAL | 时间线存在"状态空窗段"≥1个月〔S18判据继承〕 | 标注覆盖区间与空窗段；空窗段内禁止插值与外推 |
| C4_NO_SALES_DATA | 无任何销量/结构数据〔继承〕 | STEP 4b 标"不可检" |

判断 flag 是否触发以实际输入为准——输入已提供的维度不得误登记缺失 flag〔S4〕。
