# 全局执行形态协议 v1.0

**适用范围**：所有方法包。各包在 skill.md 第5节声明本包合法形态与负载画像，本文件定义规则本身。
**来源**：M03 v1.0 第5节 + S14/S15/S17/S20 判例。

---

## 1. 原则：负载决定形态

skill.md 定义方法逻辑，执行形态（单轮/分轮）由编排层决定，但方法包必须声明合法形态。复合负载（算术密度 × 生成预演 × 纪律耦合）超限是一次性大 prompt 超时的真根因〔S15：两次 20 分钟超时实证，prompt patch 无效，形态切换后 5-10 分钟级完成〕。

## 2. 形态选择

- **单轮直出（轻负载默认）**：算术密度低、无回归/重折算。已登记轻负载包：M01 / M04 / M05 / M07 / M08 / M09〔S20 转正判例：单响应连跑三轮质量无损，单轮全流程合法化〕。参考阈值：输入总行数 ≤ 20 行。
- **分轮执行（重算术）**：已登记：M02（对数回归）/ M03（ΔCost+capture 算术）/ M06（TCO 折算）。

## 3. 标准三轮范式（M03 实证，各包可按负载画像自定义切法）

| 轮 | 职责 | 输入 | 产出 |
|---|---|---|---|
| R1 算术轮 | STEP 0-2 | 主数据表切片 | 基础中间表 + flags |
| R2 判断轮 | STEP 3-5 | 话语/参照/权益表 + R1 中间表 | 判断类中间表 |
| R3 冲突装配轮 | STEP 6 + 装配 | 结构表 + 全部中间表 | diagnostic_items / conflict_resolutions / data_gap_reports / method_xref |

## 4. 分轮规则

1. 轮间传递物 = 中间表（状态外化）；后续轮基于前轮已固化中间表继续，不重算。
2. 同一窗口连跑合法（传递物为模型自产中间表）；跨窗口执行须将前轮中间表完整贴入。
3. 每轮输入只携带该轮消费的表切片 + 前轮中间表，禁止单轮携带全部输入。
4. **每轮 prompt 必须携带该轮输出 schema 全文，禁止悬空引用**（如"同前 schema"）〔S17：D5 归因判例——输出偏离先查信息可达性〕。
5. 轮内线性执行，禁反复重算、禁反复改写〔S14〕。
6. **执行包必须显式声明停止条件**〔S20：未声明导致执行引擎单响应连跑三轮无视轮界〕。

## 5. 执行预算字段（编排层设超时依据）

方法包第5节必须声明：预期检查点数上限 / 输出总规模上限 / 单轮目标时间。参考基准：M03 检查点≤10、≤6000 token、单轮≤10 分钟。
