# 全局数据契约 v1.0

**适用范围**：所有方法包的输入/输出与数据档案。各包 skill.md 第6节只写包级增量条款。
**来源**：M03 v1.0 第6节 + 数据纪律（设计总案第6节）+ 判例库。

---

## 1. 置信三档（无第四档）

| 档 | 定义 | 附加要求 |
|---|---|---|
| 官方 | 公告/财报/官方发布 | 必须带原文引句〔S12〕 |
| 第三方 | 媒体/调研/上险等 | 标注口径，与官方不可混用 |
| 估算 | 一切衍生、反推、折算值 | 附口径+全部假设〔S3〕 |

## 2. 硬规则

1. 双路径取数互洽校验（判例：两列同主题数据差 27% 被 L2 跨源碰撞抓到）；
2. 断链序列禁止插值（空窗段标注，不外推）；
3. 跨产品对比必须同期取样；
4. 估算值必须显式标注；
5. 无来源 URL 不进档案；
6. 总量数字以官方值为档案基准，第三方口径须标注不可混用（口径基准判例）。

## 3. 输入组织原则

输入按**表**组织（表A/B/C…），**不按"图表用/分析用"分类**——图表绑定的是方法执行产生的中间表，不是原始输入；图表需要的数据由"方法定义→中间表→模板绑定"链路自动决定。

## 4. 中间表

中间表 = L1 事实层的合法扩展〔S16〕。诊断项 L2/L3 引用中间表数据时，须标注来源表与行号（如 `increments[0].deltaP_wan`）。单轮场景中 L2 禁嵌未进 L1 数字的条款按原样执行。

## 5. QC 对接

数据入档前过四层：L1 代码查格式（字段/类型/URL/枚举）→ L2 代码查不变式（时窗join/算术闭合/口径混算/跨源碰撞/值越界）→ L3 QC 模型查语义（溯源核验/来源独立性，承重数字必检，异模型异上下文）→ L4 Owner 裁决争议。L1 不合格打回时必须定位到表/行/字段。
